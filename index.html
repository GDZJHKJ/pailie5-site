方法与逻辑说明

1. 数据来源

开奖号码来自中国体育彩票官方网站公开接口（中国体彩网，国家体育总局体育彩票管理中心），游戏编码 350133。 GitHub Actions 每日北京时间 22:00 自动拉取最新一期并更新 data/draws.json。号码为完整五位字符串，保留前导零。

2. 杀号排除逻辑（频率法）

对万位、千位、百位、十位、个位 每个位置独立处理：在选定窗口（如近 100 期）内统计 0-9 各数字出现次数， 取出现次数最少的 K 个数字作为该位置的“杀号候选”。直觉假设是“近期少出的数字短期内可能继续少出”， 但由于开奖各期独立同分布，该假设在统计上不成立，下方回测可验证。

3. 滑动窗口回测

将数据按时间排序，对每个测试期 t，用其前 W 期统计杀掉 K 个最低频数字， 再看第 t 期该位置实际开出的数字是否落在被杀集合中。统计命中率并与随机排除 K 个数字的理论基准 K/10 比较。长期结果应≈随机基准，说明历史频率不改变下一期概率。

4. 均匀性检验（χ²）

对每个位置在全样本上做卡方拟合优度检验（原假设：0-9 等概率），给出统计量与 p 值。 p > 0.05 时结论固定表述为“未发现显著偏离均匀分布”，不得解读为“某数字更易出”。

5. 重要结论

排列五每位为 0-9 独立等概率随机，历史频率、遗漏、冷热均不影响下一期分布。 任何“杀号/缩水/遗漏分析”策略在样本外回测中与随机不可区分，不能提高中奖概率。 本工具仅供统计学习与娱乐，请理性购彩。
